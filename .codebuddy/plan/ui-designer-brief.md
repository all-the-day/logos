# UI 设计师简报 — Logos 背经 APP

> 面向 UI 设计师（人或 AI agent）的任务简报。产品功能已开发完成，需要的是**视觉设计方案**，不是代码实现。
> 交付物建议见文末第 7 节。

## 1. 任务背景

Logos 是一款**中文圣经背诵 APP**（移动端 PWA，可安装到主屏）。核心玩法：

- 每日一屏"今日任务"：复习旧经节 + 学新经节（FSRS 间隔重复算法）
- 学习流程：**看经文 → 默写/填空背诵 → 比对评分（忘记/困难/良好/容易）→ 下一节**
- 每日签到 → 同一位置变成"每日金句"（奖励动线）
- 附带：学习笔记、数据导入导出、反馈

产品气质关键词：**安静、庄重、朴素、专注**。不是娱乐应用，是给认真背经的学习者的工具。

## 2. 当前视觉现状（真实效果）

现在是开发者的默认风格，底色干净但缺少设计感：

- **色彩**：纯白背景（#fff）＋ 近黑文字 + 10px 圆角卡片 + 浅灰细描边；**全灰阶、无品牌色**
- **唯一色彩**：进度条三色（绿=已掌握 / 橙=学习中 / 蓝=新）
- **布局**：内容 448px 居中单列，底部 3 项固定导航（计划/笔记/设置）
- **字体**：系统默认无衬线中文，正文约 16px，经文 20px、宽松行距
- **主题**：浅色 / 深色两套（CSS 变量，需同时设计）
- **风格倾向**：极简卡片式（类似 Apple 设置页 / 阅读应用），无阴影堆叠、无渐变

## 4. 设计方向建议（可自由发挥，仅作参考）

- **方向 A · 经卷质感**：米白/暖纸底色、深棕文字、衬线或宋体经文标题、细金线点缀 —— 呼应"经卷"气质
- **方向 B · 当代极简**：保持灰阶克制，用精致字体层级、更多留白、更统一的卡片语言 —— 接近现状但打磨到位
- **方向 C · 柔光阅读**：浅色柔和背景 + 毛玻璃（已有 `glass` 工具）+ 圆润卡片

## 5. 必须遵守的约束（产品动线，设计不可破坏）

1. **计划页单 CTA**：主按钮始终指向"开始今日学习"，一屏只回答一个任务
2. **签到→金句动线**：同一槽位，未签到=签到卡（含连续天数），签到后=每日金句 —— 结构不可改
3. **学习流三态**：查看→背诵→结果评分（四键 + 撤销），任何设计不能加宽流程
4. **进度三色语义**：绿=已掌握 / 橙=学习中 / 蓝=新（可换色相，但语义和区分度必须保留）
5. **删除计划**：只藏在 `…` 菜单里，主视觉不可见
6. **移动优先**：448px 内容区、底部 3 项导航；需同时考虑浅/深两主题

## 6. 技术可实现性提示（给设计师理解边界）

- 最终由 Tailwind CSS v4 + shadcn/ui 实现，设计产物需可翻译成 CSS（颜色、圆角、间距、字号可表达即可）
- 已有组件：按钮/卡片/Badge/输入框/下拉/Dialog/Tabs/进度条/底部导航
- 图标库：lucide（线性图标）

## 7. 交付物建议

1. **视觉方向**：配色方案（浅+深两套）、主/次/强调色、字体层级表、间距节奏
2. **组件风格**：按钮（主/次/危险）、卡片、输入框、Badge、进度条、列表项 的视觉规范
3. **页面设计稿**：5 个主页面（登录/计划/学习/笔记/设置），至少计划页与学习页要细化
4. **动效建议**（可选）：页面切换、评分反馈、签到→金句过渡
5. **产出格式**：设计规范文档（文字+结构图）或可直接落地的 HTML/Tailwind 原型均可
